# Bridge Buddies — Design

## Visual tone
Warm, editorial, low-pressure — serif headlines against soft gradients, not a clinical or gamified social-app feel.

## Colors
- Primary: CMU maroon `#6F1739` → near-black `#0D0D0D` gradient (brand screens: onboarding forms, Home, Chat, Campus Resources)
- Secondary: CMU gold `#C9A24B`
- Background/surface: neutral gray `#D8D8D8` → black gradient (utility screens: Splash, Login, School Select, Profile/Settings); warm off-white `#FBF9F6` cards on data-dense screens (Home dashboard modules), pure white `#FFFFFF` on form/input screens
- Mode: light only for v1

## Typography
Display serif (Playfair Display) for headlines/logo/greetings; system sans for body, labels, buttons. Type scale follows a 4px-step system: 12/16/20/24/28/32/40px.

## Brand carryover
None — Bridge Buddies is a fresh identity, not reusing MANK Studios or XSkill branding. Full spec lives in `UI_SPEC.md`, which this Design.md summarizes; treat UI_SPEC.md as the authoritative detail source for components and screen layouts.
